Connect to GitHub

Publishing saves your changes straight to the website. It needs a GitHub access token, which is remembered in this browser only. One-time setup:

  1. Open GitHub → New fine-grained token (sign in as rajkallamadi).
  2. Token name: Apprendre admin. Expiration: your choice (e.g. 1 year).
  3. Repository access: Only select repositories → apprendre.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it below.

Only use this on your own computer. Anyone using this browser can publish until you click Forget GitHub Token in the sidebar.
